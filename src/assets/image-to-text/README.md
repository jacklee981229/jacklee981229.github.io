# Image to Text's models

PaddleOCR's PP-OCRv6 tiny text detection and recognition models, as ONNX, exactly as PaddlePaddle publishes them:

- `PP-OCRv6_tiny_det.tar` from https://paddle-model-ecology.bj.bcebos.com/paddlex/official_inference_model/paddle3.0.0/PP-OCRv6_tiny_det_onnx_infer.tar
- `PP-OCRv6_tiny_rec.tar` from https://paddle-model-ecology.bj.bcebos.com/paddlex/official_inference_model/paddle3.0.0/PP-OCRv6_tiny_rec_onnx_infer.tar
